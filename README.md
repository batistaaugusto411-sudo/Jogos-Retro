# 🎮 GameZone Retro - Landing Page

Este é um projeto simples em HTML5 desenvolvido para a landing page da **GameZone Retro**, apresentando informações sobre a loja, catálogo de consoles clássicos disponíveis, link para download de aplicativo emulador e uma tabela com os preços dos jogos.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação do conteúdo, navegação interna por âncoras, links externos, exibição de mídia (imagem), listas e tabela de preços.

---

## 🗂️ Estrutura da Página

A página contém os seguintes elementos principais:

* **Cabeçalho & Apresentação:** Título principal da GameZone Retro e slogan da loja.
* **Links e Mídia:** 
  * Link de atalho interno para a seção de preços (`#secao1`).
  * Link externo para o aplicativo emulador na Google Play Store.
  * Imagem promocional principal (`retro.jpg`).
* **Lista de Consoles:** Exibição dos consoles retrô disponíveis na loja.
* **Tabela de Preços:** Tabela organizando os jogos clássicos, seus respectivos consoles e valores de venda.
* **Rodapé:** Direitos autorais e ano de criação da loja.
